# Third-Party Material, Provenance, and Attribution

This project is an **independent** implementation. Materials created by other authors retain their original rights, attribution requirements, and licenses. The project's [MIT](LICENSE) and [CC BY-NC-SA 4.0](CONTENT_LICENSE.md) licenses apply only where the project's contributors have the right to grant them.

## Exception to directory defaults

The path-based licensing rules in [README.md](README.md) apply only to **original project contributions**. Neither storing a third-party file under `content/` nor committing it to a code directory changes its copyright or license. Put approved third-party assets in `static/third-party/`, preserve their own terms, and record source, author, permission/license, any modifications, and attribution below. If permissions are incompatible or unclear, **do not import the file**.

Generated HTML, PDF, and EPUB files may incorporate material from multiple sources. Each incorporated work retains its own license, so the build output is not automatically wholly MIT or wholly CC BY-NC-SA.

## PDFs, EPUBs, MOBI files, and upstream translations

The initial website **links to the original publication sources** rather than copying original PDF, EPUB, or MOBI files or original translations into this repository.

- Link to the official source pages rather than assuming the existence of a permanent binary download URL.
- A link does not transfer ownership or grant permission to copy or edit the linked work.
- New exports from Markdown may be introduced later **only for content the project is authorized to reproduce, adapt, and export**.

## Other imported assets and code

If fonts, icons, images, code fragments, or other third-party materials are later included:

1. Verify the exact source and copyright holder(s).
2. Verify that the applicable license or permission allows the intended use.
3. Retain required notices and attribution, including a clear path to the affected file(s).
4. Avoid importing the asset if terms are unknown or incompatible.
5. Do not imply that the repository's default licenses override the asset's actual license.

## Corrections and rights inquiries

If you believe an attribution or license is missing or inaccurate, please open a GitHub issue with a link to the relevant work and supporting source information. Maintainers should investigate and, where necessary, remove or replace material pending clarification.
