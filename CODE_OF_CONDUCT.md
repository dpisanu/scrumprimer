# Code of Conduct

The Scrum Primer independent website project aims to provide a respectful, constructive environment for everyone participating in its issues, pull requests, discussions, and other project spaces.

## Expected conduct

- Be respectful and focus criticism on ideas and work, not personal traits.
- Communicate constructively and assume good faith while addressing disagreements.
- Respect differing backgrounds, identities, experience levels, and viewpoints.
- Follow the project's contribution, licensing, and attribution requirements.

Unacceptable conduct includes harassment, discrimination, personal attacks, deliberate intimidation, and repeated disruptive behavior.

## Applying these standards

Project maintainers are responsible for addressing reported conduct. They may edit or remove content, close discussions or pull requests, or restrict participation when necessary. Responses should be proportionate to the conduct and applied consistently.

To report a concern, contact a repository maintainer through GitHub. Do not include private or sensitive information in a public issue. Maintainers will handle reports as discreetly as the available GitHub tools allow.
